# Linear Force · Landing page

Landing page de lanzamiento del distractor articular **Linear Force** de Biosurgex.

Sitio estático (HTML + CSS + JS, sin dependencias ni paso de build). Todo el contenido está en `index.html` y las imágenes en `img/`.

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Despliegue

Desplegado en Vercel. Cada push a `main` publica la versión en producción.
